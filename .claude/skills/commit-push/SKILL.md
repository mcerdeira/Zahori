# Commit y push

Siempre hacer commits, lo mas granulares posibles y con descripciones en español (no mas extensas que una oración). Al estar trabajando yo solo no hace falta usar branches (salvo que explicitamente lo pida) por lo que lo normal del workflow es:

Trabajar en un feature o issue sobre main -> Hacer el commit -> hacer el push a main
